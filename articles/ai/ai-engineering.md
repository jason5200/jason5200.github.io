## 一、从 Demo 到工程化的差距

前面几篇讲了端侧推理、语音助手、Agent 的「原理」。但把一个 Demo 变成**可上车的工程**，中间隔着一大堆工程问题：

```
Demo：本地跑通一个模型推理
        │
        │  工程化要解决 ↓
        ▼
工程：模型管理、性能、内存、功耗、监控、热更新、兼容性...
```

这一篇聚焦这些「落地必踩的坑」。

## 二、模型管理与分发

### 1. 模型版本化

模型是「会迭代的代码」，必须版本化管理：

```
model-v1.bin  →  模型 v1（初始版本）
model-v2.bin  →  模型 v2（微调优化）
```

- 模型文件和 App 版本**解耦**，独立下发。
- 记录模型版本 → 效果 → 问题的对应关系。

### 2. 模型下载与更新

模型体积大（几百 MB 到几个 GB），不能打包进 APK：

```
App 启动
   │
   ├── 检查本地模型版本
   ├── 对比服务端最新版本
   ├── 需要更新 → 后台下载（断点续传 + 校验）
   └── 下载完成 → 校验哈希 → 原子替换
```

**关键**：
- 下载要**断点续传**、**校验哈希**（防损坏/篡改）。
- 替换要**原子操作**（先下载到临时文件，校验通过再替换）。

## 三、性能优化

### 1. 硬件加速

端侧推理必须利用硬件加速，否则 CPU 跑大模型慢到不可用：

| 硬件 | 加速能力 | 框架支持 |
|------|----------|----------|
| CPU | 基础 | 所有框架 |
| GPU | 中等 | MNN/ONNX/NCNN |
| NPU/DSP | 最强 | 需厂商 SDK（如高通 SNPE、联发科 NeuroPilot） |

**实践**：优先 NPU，回退 GPU，再回退 CPU。运行时动态选择可用后端。

### 2. 推理参数调优

| 参数 | 影响 | 建议 |
|------|------|------|
| maxTokens | 生成长度 | 车机场景设小（如 256），控制延迟 |
| temperature | 随机性 | 意图识别低（0.1），闲聊可高（0.7） |
| 量化精度 | 速度 vs 精度 | INT4 最快，FP16 最准 |

## 四、内存与功耗管理

端侧模型常驻内存，是内存和功耗大户：

### 内存

- 模型**常驻内存**，避免反复加载（加载一次要几秒）。
- 监控内存占用，必要时**卸载不用的模型**。

### 功耗

- 推理是高耗电操作，**限制推理频率**。
- 闲时（如停车）可以跑重型任务，行驶中只跑轻量任务。

## 五、监控与可观测性

工程化必须有监控，否则出问题无从排查：

| 指标 | 说明 |
|------|------|
| 推理延迟 | P50/P95/P99 延迟 |
| 首 token 延迟 | 用户感知的关键指标 |
| 生成速度 | tokens/s |
| 内存/功耗 | 资源占用 |
| 错误率 | 推理失败、超时 |
| 模型效果 | 用户满意度、纠错率 |

**实践**：埋点上报这些指标，建立 dashboard，模型迭代有据可依。

## 六、端云协同的工程实现

前面讲了端云协同的概念，工程上要落地：

```
请求进入
   │
   ▼
路由层（判断走端侧还是云端）
   ├── 规则：简单/敏感/离线 → 端侧
   ├── 规则：复杂/需强推理 → 云端
   │
   ▼
端侧推理 或 云端 API
   │
   ▼
统一返回格式
```

**关键**：路由策略要**可配置**（服务端下发），不是写死在代码里。

## 七、安全与合规

车机上的 AI 涉及安全：

- **模型加密**：防止模型文件被逆向提取。
- **数据脱敏**：上传云端的数据要脱敏（去标识化）。
- **权限控制**：语音、位置等敏感数据的使用要合规。

## 八、落地 Checklist

把端侧 AI 上车，需要打勾的清单：

- [ ] 模型版本化 + 独立分发
- [ ] 下载断点续传 + 哈希校验 + 原子替换
- [ ] NPU/GPU/CPU 多后端回退
- [ ] 推理参数可配置
- [ ] 内存/功耗监控
- [ ] 延迟/token速度埋点
- [ ] 端云协同路由可配置
- [ ] 模型加密 + 数据脱敏

## 九、总结

| 维度 | 要点 |
|------|------|
| 模型管理 | 版本化、独立分发、原子替换 |
| 性能 | NPU 加速、参数调优 |
| 资源 | 内存常驻管理、功耗控制 |
| 监控 | 延迟/token速度/错误率埋点 |
| 协同 | 端云路由可配置 |
| 安全 | 加密、脱敏、合规 |
