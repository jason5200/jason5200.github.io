# Agent 在车机场景的应用

> 系列：AAOS-Guide · 05-ai-integration
> 难度：⭐⭐⭐ 进阶
> 前置知识：《大模型上车：端侧推理》《车载语音助手》

---

## 一、从「聊天机器人」到「Agent」

前面讲的语音助手，本质是「一问一答」的聊天机器人。但**Agent（智能体）** 更进一步：

> Agent = 大模型 + 工具 + 记忆 + 规划，能**自主完成多步任务**。

区别：

| | 聊天机器人 | Agent |
|---|-----------|-------|
| 交互 | 一问一答 | 多步自主执行 |
| 能力 | 只会"说" | 会"想" + "做"（调工具） |
| 例子 | "今天天气怎么样" | "规划回家路线，避开拥堵，顺路加个油" |

## 二、Agent 的核心组成

```
Agent
 ├── LLM（大脑）：理解 + 推理 + 决策
 ├── 工具（手）：Function Calling 调用的各种能力
 ├── 记忆（经验）：短期（对话上下文）+ 长期（用户偏好）
 └── 规划（策略）：把大任务拆成小步骤
```

**规划**是 Agent 区别于聊天机器人的关键——它能**把一个复杂目标拆解成多步**，逐步执行，并根据结果调整。

## 三、车机场景的典型 Agent 任务

### 1. 行程规划 Agent

```
用户："下班回家，顺便加个油"

Agent 拆解：
1. 查当前油量 → 低，需要加油
2. 查回家路线上最近的加油站
3. 规划路线：先加油 → 再回家
4. 调用导航 API，生成完整路线
5. 播报："已为您规划：先到 XX 加油站，再回家，预计 40 分钟"
```

涉及工具：油量查询、POI 搜索、导航、TTS。

### 2. 车辆健康管家 Agent

```
用户："我的车最近好像有点费油"

Agent 拆解：
1. 读车辆数据（油耗、胎压、里程）
2. 分析异常（对比历史数据）
3. 给出诊断建议（"胎压偏低，建议检查"）
4. 预约附近 4S 店
```

### 3. 个性化座舱 Agent

```
Agent 学习用户习惯：
- 早上 8 点上车 → 自动导航到公司
- 周五下班 → 推荐周末去处
- 根据心情 → 调整氛围灯 + 音乐
```

## 四、Agent 的技术实现要点

### 1. 工具调用（Function Calling）

Agent 的"手"，把车机能力封装成工具：

```kotlin
// 定义工具：查油量
val tools = listOf(
    Tool(
        name = "get_fuel_level",
        description = "查询当前剩余油量百分比",
        parameters = emptyMap()
    ),
    Tool(
        name = "navigate_to",
        description = "导航到指定目的地",
        parameters = mapOf("destination" to "string")
    )
)

// LLM 决策后返回工具调用请求，业务层执行
```

### 2. 记忆系统

- **短期记忆**：对话上下文（多轮对话）
- **长期记忆**：用户偏好（常用地点、音乐口味），存本地数据库

### 3. 规划与反思

```
用户目标
   │
   ▼
LLM 生成计划（步骤 1 → 2 → 3）
   │
   ▼
逐步执行，观察结果
   │
   ├── 成功 → 继续下一步
   └── 失败 → LLM 反思，调整计划
   │
   ▼
完成任务，总结
```

这就是 Agent 的 **Plan-Execute-Reflect** 循环。

## 五、车机 Agent 的挑战

| 挑战 | 说明 | 对策 |
|------|------|------|
| **安全** | 自主执行可能误操作（如错误导航） | 关键操作需用户确认 |
| **可靠性** | 多步任务中途失败 | 完善错误处理 + 反思机制 |
| **延迟** | 多步推理耗时 | 端云协同，简单任务端侧 |
| **上下文** | 车机场景上下文复杂 | 融入车辆状态作为上下文 |

## 六、落地建议

| 阶段 | 目标 | 方案 |
|------|------|------|
| MVP | 单工具调用 | Function Calling 打通一个场景 |
| 进阶 | 多步任务 | 引入规划 + 多工具编排 |
| 成熟 | 个性化 | 长期记忆 + 用户画像 |

## 七、总结

| 要点 | 结论 |
|------|------|
| Agent 是什么 | LLM + 工具 + 记忆 + 规划 |
| 与聊天机器人区别 | 能自主完成多步任务 |
| 车机场景 | 行程规划、车辆健康、个性化座舱 |
| 核心机制 | Function Calling + Plan-Execute-Reflect |
| 最大挑战 | 安全与可靠性 |
